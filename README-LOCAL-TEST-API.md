# Локальный тестовый Web API

Это исключительно mock-сервер для локальной проверки TrayService. Он использует стандартную библиотеку Python и слушает только 127.0.0.1:8765. Это НЕ production-сервер, не настоящий JWT-сервер и не криптографически защищённая лицензия.

## 1. Запустить API
1. Установите Python 3.10+ с python.org (если ещё не установлен).
2. Откройте PowerShell в папке проекта, где лежит `mock_api.py`.
3. Выполните `py mock_api.py` (или `python mock_api.py`). Оставьте окно открытым.
4. Проверьте в браузере `http://127.0.0.1:8765/health` — должен появиться JSON со статусом `ok`.

## 2. Настроить TrayService
В `TrayService.ini` рядом с `TrayService.exe` установлены тестовые значения:
`base_url=http://127.0.0.1:8765` и `allow_insecure_loopback_http=1`. Если файл конфигурации в выходную папку не скопировался, скопируйте туда `TrayService.ini` из проекта. Перезапустите службу после изменения INI: `sc.exe stop TrayService`, затем `sc.exe start TrayService`.

## 3. Проверка в UI
- Логин: `demo`
- Пароль: `demo123`
- Код активации: `TEST-2026`
- Для проверки ошибочного входа используйте неверный пароль; для ошибочной активации — любое другое значение.

Ожидаемое поведение: вход выдаёт тестовые токены; проверка лицензии до активации показывает отсутствие лицензии; активация создаёт тестовую лицензию на 30 дней; повторная проверка показывает дату истечения. Mock-ответы содержат `expires_in=120` и `ticket_ttl_seconds=60`, чтобы обновление можно было тестировать быстрее.

## 4. Важные ограничения
- В mock API токены являются случайными строками, а не JWT. Это намеренно: API лишь имитирует контракт, ожидаемый текущим кодом службы.
- Данные тестовых лицензий хранятся только в памяти mock-сервера и исчезнут после его остановки.
- HTTP разрешён в C++ только при явном `allow_insecure_loopback_http=1` и адресе `http://127.0.0.1:...`. Не выставляйте такой сервер наружу и не используйте этот режим в production. Обычные адреса по-прежнему требуют HTTPS.
- Для production нужны реальный сервер, HTTPS с валидным сертификатом, настоящий JWT, авторизация, отзыв/ротация refresh-токенов, база данных, контроль устройств и полноценная модель лицензии.
- Python `http.server`/`BaseHTTPRequestHandler` предназначен для разработки, не для production. См. документацию Python: https://docs.python.org/3/library/http.server.html
